# Sentinel DE Sandbox

## Overview

This repository serves as a development sandbox for the Sentinel Analytics Data Engineering team.

It will be used to develop, test, and maintain data engineering workflows and related components as part of the Sentinel data platform.

## Development Environment

- Python 3.12
- Git
- Virtual environment (`venv`)

## Local Setup

Clone the repository:

    git clone <https://github.com/Hemant-A-Singh/sentinel-data-platform>

Configur user name and email in your local git
    git config --global user.name <"Name">
    git config --global user.email = <"Email">

Navigate to the project directory:

    cd sentinel-data-platform

Create a virtual environment:

    python3 -m venv .venv

Activate the virtual environment:

    source .venv/bin/activate
